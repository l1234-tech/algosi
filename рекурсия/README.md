# Рекурсия

Рекурсия — способ решения задачи, при котором функция вызывает саму себя для более простого подслучая.

## Две обязательные части рекурсивного решения

1. **Базовый случай** — условие остановки рекурсии.
2. **Рекурсивный переход** — сведение задачи к более простому подслучаю.

Если базового случая нет или каждый вызов не приближает к нему, рекурсия может не завершиться и привести к переполнению стека.

## Что важно понимать

- Как формулируется базовый случай.
- Как изменяются аргументы между вызовами.
- Как возвращаются результаты из рекурсивных вызовов.
- Как оценивать глубину рекурсии и расход памяти стека.
- Когда итеративное решение может быть предпочтительнее.
