# Algorithms & Data Structures

> Учебный репозиторий по алгоритмам и структурам данных: конспекты, практические задания, решения и материалы курса.

## Навигация

| Тема | Что внутри |
|---|---|
| [Оценка сложности](./оценка_сложности/) | Асимптотика алгоритмов, оценка времени и памяти |
| [Рекурсия](./рекурсия/) | Рекурсивные функции, базовый случай и стек вызовов |
| [Базовые структуры данных](./базовые_структуры_данных/) | Базовые способы хранения и обработки данных |
| [Сортировки](./сортировки/) | Алгоритмы сортировки и их сравнение |
| [Кучи](./кучи/) | Куча, операции и связанные задачи |
| [Бинарные деревья поиска](./бинарные_деревья_поиска/) | Поиск, вставка, удаление и обход дерева |

## Как устроена тема

В тематической папке ищи:

- `теория/` — лекции, конспекты и дополнительные материалы;
- `прак/` — практические задания, если они предусмотрены;
- `дз/` — домашние задания;
- `contest.md` — ссылка на Яндекс Контест, если он есть.

Структура каталогов постепенно приводится к единому виду, поэтому в старых разделах названия папок могут отличаться.

## Языки

Решения представлены преимущественно на Python, в отдельных задачах используется C++.

## Как запускать решения

Для Python 3 перейди в каталог нужной задачи и запусти файл:

```bash
python solution.py
```

Некоторые старые решения используют `input.txt` или другие файлы. Перед запуском проверь, откуда программа читает входные данные и куда выводит результат. Если задача предназначена для контестной платформы, формат ввода и вывода должен соответствовать условию.

## Принцип оформления решения

По возможности для каждой задачи сохраняются:

1. условие задачи или ссылка на него;
2. краткая идея алгоритма;
3. исходный код;
4. оценка временной и пространственной сложности;
5. тестовые случаи и результат проверки.

## Назначение репозитория

Репозиторий используется для систематизации учебных материалов, повторения теории и практики алгоритмов и структур данных.
