## Как сравнивать алгоритмы сортировки

При изучении каждой сортировки полезно фиксировать:

- временную сложность в лучшем, среднем и худшем случаях, если это применимо;
- дополнительную память;
- устойчивость;
- выполняется ли сортировка на месте;
- ограничения и случаи, когда алгоритм удобен.

## Часто используемые алгоритмы

| Алгоритм | Типичная временная сложность | Дополнительная память |
|---|---:|---:|
| Сортировка вставками | (O(n^2)) в среднем и худшем случаях | (O(1)) для стандартной реализации на месте |
| Сортировка слиянием | (O(n \log n)) | Обычно (O(n)) |
| Быстрая сортировка | (O(n \log n)) в среднем, (O(n^2)) в худшем случае | Зависит от реализации и глубины рекурсии |
| Пирамидальная сортировка | (O(n \log n)) | (O(1)) дополнительной памяти для стандартной реализации на месте |

Это справочная таблица для распространённых вариантов алгоритмов; конкретные оценки нужно сверять с реализацией.
