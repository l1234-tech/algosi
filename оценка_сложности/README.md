## Основные обозначения

- `O(f(n))` — асимптотическая верхняя оценка роста.
- \(\Theta(f(n))\) — точная асимптотическая оценка с точностью до постоянных множителей.
- \(\Omega(f(n))\) — асимптотическая нижняя оценка.

При анализе важно отдельно оценивать время и дополнительную память. Сложность зависит от алгоритма, структуры данных и, в некоторых задачах, от свойств входных данных.

## Часто встречающиеся классы

| Сложность | Пример интуитивного роста |
|---|---|
| `O(1)` | Не зависит от размера входа |
| (O(\log n)) | Размер задачи уменьшается в постоянное число раз |
| `O(n)` | Один проход по входу |
| (O(n \log n)) | Многие эффективные алгоритмы сортировки |
| `O(n²)` | Два вложенных прохода по данным |
