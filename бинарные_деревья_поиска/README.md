# Бинарные деревья поиска

Бинарное дерево поиска (BST) — структура данных, в которой ключи левого поддерева меньше ключа узла, а ключи правого поддерева больше него (если реализация не допускает дубликаты).

## Основные операции

| Операция | Обычное BST, в зависимости от высоты (h) | Худший случай |
|---|---:|---:|
| Поиск | `O(h)` | `O(n)` |
| Вставка | `O(h)` | `O(n)` |
| Удаление | `O(h)` | `O(n)` |
| Обход всего дерева | `O(n)` | `O(n)` |

Для сбалансированного дерева высота порядка (O(\log n)). Обычное BST не гарантирует баланс: при неудачном порядке вставок оно может выродиться в цепочку.

## Что важно понять

- Как устроен узел: ключ, левый и правый потомки.
- Как работают поиск и вставка.
- Как удалять лист, узел с одним ребёнком и узел с двумя детьми.
- Чем отличаются прямой, симметричный и обратный обходы.
- Почему высота влияет на сложность операций.
- Чем обычное BST отличается от AVL-дерева и других самобалансирующихся деревьев.
