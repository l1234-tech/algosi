## B-дерево

В текущем практическом файле рассматривается работа с B-деревом: поиск ключа и вставка с разделением заполненных узлов. B-дерево хранит несколько ключей в одном узле и поддерживает сбалансированную высоту, что полезно для работы с большими объёмами данных.

Для B-дерева минимальной степени (t):

- узел, кроме корня, содержит от (t-1) до (2t-1) ключей;
- внутренний узел с (k) ключами имеет (k+1) потомков;
- все листья находятся на одном уровне;
- поиск и вставка имеют логарифмическую по числу ключей высоту дерева; стоимость обработки ключей внутри узла зависит от (t).
