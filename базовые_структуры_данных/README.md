## Состав раздела

В папке `дз/` находятся пять пронумерованных задач. Условия сохранены рядом с соответствующими решениями в виде изображений.

## Как работать с разделом

1. Изучи лекцию и выпиши назначение каждой структуры.
2. Для каждой задачи сначала сформулируй, какие операции нужны и сколько они должны стоить.
3. Реализуй решение и проверь его на простом примере и граничных случаях.
4. Сверь формат ввода и вывода с условием контеста.
