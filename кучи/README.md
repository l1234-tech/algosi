# Кучи

Куча — структура данных, которая позволяет эффективно получать минимальный или максимальный элемент. Она часто используется для реализации приоритетной очереди.

## Основные свойства

Для стандартной бинарной кучи, хранящейся в массиве:

| Операция | Типичная сложность |
|---|---:|
| Получить минимум/максимум | (O(1)) |
| Вставить элемент | (O(\log n)) |
| Извлечь корень | (O(\log n)) |
| Построить кучу из массива | (O(n)) |

Эти оценки относятся к обычной бинарной куче; у других разновидностей куч набор операций и оценки могут отличаться.

## Что важно понять

- Разница между min-heap и max-heap.
- Связь индексов родителя и потомков в массиве.
- Просеивание вверх и вниз.
- Построение кучи и сортировка кучей.
- Чем бинарная куча отличается от биномиальной.
